## Qué hago
- Desarrollo de APIs REST y GraphQL orientadas a producción.
- Diseño de arquitectura para microservicios y comunicación entre servicios.
- Modelado y optimización en bases de datos relacionales y migraciones.
- Observabilidad: logs estructurados, métricas y trazas distribuidas.
- Automatización de CI/CD y despliegues en contenedores/cluster.
- Seguridad en API: autenticación, autorización, validación y rate-limits.

## Buenas prácticas que aplico
- Documentación con OpenAPI / contratos versionados.
- Testing automatizado: unitarios, integración y contract tests.
- Observabilidad: Prometheus, OpenTelemetry, trazas distribuidas.
- Estrategias de caché y diseño para baja latencia.
- Seguridad: validación, manejo de secretos, control de accesos y auditoría.
- CI/CD con tests y despliegues controlados (rollbacks seguros).

## Proyectos destacados
- Servicio de autenticación/autorization (OAuth2, JWT) con integración SSO.
- Procesamiento asíncrono y pipelines de ingesta con workers y colas.
- APIs críticas con migraciones y compatibilidad entre versiones.
- Pipelines CI/CD para despliegues en Kubernetes.
